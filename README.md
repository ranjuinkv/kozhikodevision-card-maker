# കോഴിക്കോട് വിഷൻ - ന്യൂസ് കാർഡ് മേക്കർ (Kozhikode Vision News Card Maker)

കോഴിക്കോട് വിഷൻ ചാനൽ റിപ്പോർട്ടർമാർക്ക് ഫീൽഡിൽ നിന്ന് അതിവേഗം ഫോട്ടോ അപ്‌ലോഡ് ചെയ്ത് ബ്രാൻഡഡ് ന്യൂസ് കാർഡുകൾ (News Posters) നിർമ്മിക്കാനുള്ള മൊബൈൽ ആപ്പ്.

---

### പ്രധാന സവിശേഷതകൾ:
1. **ഫോട്ടോ അപ്‌ലോഡ് & ക്യാമറ**: മൊബൈൽ ക്യാമറയിൽ നിന്നോ ഗാലറിയിൽ നിന്നോ ഫോട്ടോ എടുക്കാം.
2. **മലയാളം ടൈപ്പോഗ്രാഫി**: മലയാളം ഫോണ്ടുകൾ (Anek Malayalam, Manjari) ഉപയോഗിച്ച് വ്യക്തമായ അക്ഷരങ്ങൾ.
3. **ഓഫീഷ്യൽ ബ്രാൻഡിംഗ്**: കോഴിക്കോട് വിഷൻ ലോഗോ, ലൈവ് ബാഡ്ജ്, ലൊക്കേഷൻ (📍), തീയതി (🗓️), റിപ്പോർട്ടർ ടാഗ് (🎤).
4. **മൾട്ടിപ്പിൾ സൈസുകൾ**:
   - `1:1` - WhatsApp / Facebook / Instagram പോസ്റ്റുകൾ
   - `9:16` - WhatsApp സ്റ്റാറ്റസ് / ഇൻസ്റ്റാഗ്രാം സ്റ്റോറികൾ
   - `16:9` - യൂട്യൂബ് തംബ്‌നെയിൽ / ടിവി സ്ക്രോൾ
5. **തീമുകൾ**: ബ്രേക്കിംഗ് ന്യൂസ് (റെഡ്), പ്രധാന വാർത്ത (ബ്ലൂ), പ്രാദേശികം (ഗ്രീൻ), സ്പെഷ്യൽ (ഗോൾഡ്), ആദരാഞ്ജലി (ഡാർക്ക്).
6. **വൺ-ടാപ്പ് ഷെയർ & ഡൗൺലോഡ്**: ഒരൊറ്റ ക്ലിക്കിൽ വാട്ട്‌സ്ആപ്പിലേക്ക് ഷെയർ ചെയ്യാം അല്ലെങ്കിൽ ഫോൺ ഗാലറിയിലേക്ക് HD ആയി ഡൗൺലോഡ് ചെയ്യാം.

### എങ്ങനെ APK ആക്കി മാറ്റാം? (How to generate APK)

#### വഴി 1: PWABuilder (ഏറ്റവും എളുപ്പമുള്ള വഴി - 2 മിനിറ്റ്)
1. ഈ ഫോൾഡറിലെ ഫയലുകൾ സൗജന്യമായി [Netlify Drop](https://app.netlify.com/drop) അല്ലെങ്കിൽ GitHub Pages-ലേക്ക് അപ്‌ലോഡ് ചെയ്യുക.
2. ലഭിക്കുന്ന ലിങ്ക് [PWABuilder.com](https://www.pwabuilder.com) എന്ന വെബ്സൈറ്റിൽ നൽകുക.
3. **Build APK** ക്ലിക്ക് ചെയ്താൽ റെഡിമെയ്ഡ് Android APK ഫയൽ തത്സമയം ഡൗൺലോഡ് ചെയ്യാം!

#### വഴി 2: ഇൻസ്റ്റന്റ് ഇൻസ്റ്റാൾ (Install as Mobile App)
- ഈ വെബ് ലിങ്ക് റിപ്പോർട്ടർമാരുടെ മൊബൈലിൽ (Chrome ബ്രൗസറിൽ) തുറക്കുക.
- മുകളിലെ 3 ഡോട്ടുകൾ ക്ലിക്ക് ചെയ്ത് **"Add to Home screen" (Install App)** കൊടുക്കുക.
- പ്ലേസ്റ്റോർ ഇല്ലാതെ തന്നെ ആപ്പ് ആയി ഫോൺ സ്ക്രീനിൽ ഐക്കൺ വരും. ഓഫ്‌ലൈനിലും പ്രവർത്തിക്കും!
